# Cambios v5: empleados y concentrado

- Se agregó eliminación definitiva de empleados desde el panel.
- Al eliminar un empleado se eliminan sus solicitudes e históricos y, si era líder, sus colaboradores quedan sin líder asignado.
- El concentrado de empleados ahora muestra los días de vacaciones ya tomados y los días apartados o pendientes.
- El Excel usa una hoja `Concentrado` con columnas separadas para días tomados y días apartados.
- La exportación excluye automáticamente registros cuyo número de empleado comienza con `LIDER`.
